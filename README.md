# Nandi Delices Application Specification

This package defines the first version of the Nandi Delices restaurant ordering application.

## Main behavior

**Menu → Cart → Checkout → Open WhatsApp with pre-filled order**

The customer manually taps **Send** in WhatsApp.

## Files

- `REQUIREMENTS.md` — complete product requirements.
- `WORKFLOW.md` — customer and future admin workflows.
- `UI_SPEC.md` — visual/UI specification based on the supplied menu and logo.
- `DATA_MODEL.md` — menu/cart/checkout/config structures.
- `IMPLEMENTATION_PLAN.md` — development phases and WhatsApp integration.
- `menu.json` — 37 menu entries transcribed from the supplied menu image.
- `reference_menu.jpeg` — supplied menu reference.
- `reference_logo.jpeg` — supplied logo reference.
